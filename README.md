# RPG

2D 탑다운 실시간 액션 RPG.

## 현재 버전

기획서의 주요 시스템을 한 번에 연결한 **통합 플레이 프로토타입**입니다.

### 들어간 시스템
- 마을 / 사냥터 7종
- 플레이어 이동 / 공격 / 스킬
- 7종 무기 + 주먹 + 수호자의 무기
- 레벨 / EXP / 6종 스탯 / 스탯 포인트
- HP / MP / 회복
- 몬스터 전투 / 드롭 / 골드 / 사망
- 인벤토리
- 상점 / 구매 / 판매
- 장비 선택 / 강화
- 장비 제작
- 퀘스트 보상 흐름
- 농장 / 작물 수확
- 닭 / 돼지 / 소
- 도축
- 낚시
- 광산 / 광물
- 요리
- 집 구매
- 100개 일반 업적 데이터
- 7개 히든 업적 데이터
- 10층 탑 / 탑의 수호자 / 엔딩
- 5개 저장 슬롯
- 자동 저장
- 기본 UI / HUD

## 조작

- 방향키: 이동
- Space: 공격
- Q: 무기 스킬
- F: 상호작용
- E: 상태창
- ESC: 메뉴

## 실행

GitHub Pages 또는 로컬 브라우저에서 `index.html`을 실행할 수 있습니다.

## 개발 원칙

현재 버전은 모든 주요 시스템을 실제로 연결해 보는 통합 프로토타입입니다.

이후 작업에서는 새 시스템을 추가하기보다, 각 시스템을 확정 기획의 수치와 규칙에 맞게 다듬고 버그를 잡으며 완성도를 올리는 것을 우선합니다.

Godot 사용은 고정하지 않습니다. 실제로 완성하기 쉬운 방법을 사용합니다.
