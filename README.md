# RPG

2D 탑다운 실시간 액션 RPG 프로토타입.

## 현재 목표
기획서에 정리된 시스템을 실제로 플레이 가능한 형태로 하나씩 구현한다.

## 실행
브라우저에서 실행되는 HTML/CSS/JavaScript 프로토타입으로 시작한다.

- index.html을 브라우저에서 열기
- GitHub Pages에 연결하면 웹에서 바로 실행 가능

## 현재 구현
- 마을 / 사냥터 선택
- 방향키 이동
- Space 공격
- 기본 몬스터 전투
- HP / MP / EXP / 골드
- 레벨업과 스탯 포인트
- F 상호작용
- E 상태창
- ESC 메뉴
- 로컬 저장
- 기본 무기 데이터
- 사망 처리
- 기본 포탈 이동 구조

## 다음 구현 우선순위
1. 무기별 공격과 스킬
2. 인벤토리 / 장비 / 상점
3. 강화
4. 퀘스트
5. 농장 / 가축 / 요리 / 낚시 / 광산
6. 업적
7. 탑과 탑의 수호자
8. 최종 저장 시스템과 마무리

## 개발 원칙
새 시스템을 무작정 추가하지 않고 현재 확정된 기획을 먼저 완성한다.
Godot 사용 여부는 고정하지 않으며, 실제 완성이 쉬운 방법을 우선한다.
